# Model Card — Rated CO₂ Early-Specification Regressor

This document defines how I interpret the model generated by `python run_pipeline.py`.
The selected estimator and exact metrics are written at runtime to:

- `data/outputs/model_metadata.json`
- `data/outputs/model_metrics.csv`
- `data/outputs/model_segment_errors.csv`
- `data/outputs/feature_importance.csv`

## Intended Use

- compare model candidates using a future-year validation period;
- estimate published rated tailpipe CO₂ before measured consumption fields are used;
- rank configurations for additional analytical review;
- demonstrate leakage-aware regression and temporal evaluation.

## Features

The primary model uses model year, engine size, cylinders, gear count, make,
canonical vehicle class, transmission family, and fuel type.

## Excluded Features

City, highway, and combined fuel consumption, combined MPG, CO₂/smog ratings,
target-derived class-year benchmarks, and the free-text model label are excluded.
This prevents circular target reconstruction and high-cardinality memorization.

## Evaluation Design

- MY1995–2019: training
- MY2020–2021: model selection
- MY1995–2021: final refit
- MY2022–2023: untouched test period

MAE is the primary metric. RMSE, MAPE, R², mean error, P90 absolute error, and
segment-level errors are also generated for review.

## Limitations

The model estimates published Canadian tailpipe ratings, not real-world or lifecycle
emissions. It excludes weight, power, torque, aerodynamics, drivetrain detail,
electrification flags, sales counts, and distance traveled. It is not suitable for
regulatory, safety, credit, or procurement decisions.

## Reproducibility Rule

I do not place fixed result values in this source-only package. Any result quoted in
the README, CV, or interview must match the artifacts produced by the final local run.
